## 验证策略

- 搬迁原有离线测试，在工具环境执行；不需要加载模型、仿真或训练环境。
- 用合成日志验证训练、offline-eval、B1K 本地/云端/重复 namespace 的结果口径。
- 飞书网络使用 mock；不以发送真实测试卡片作为自动验收前提。
- 启停测试验证进程身份、单实例、独立 PID、停止时子进程清理和秘密不输出。
- 检查生产文件迁移前后哈希与入口依赖；实际监控只做进程替换，不碰业务进程。
- 旧独立遥控仓库保留 Git 历史归档，不删除历史或覆盖本机凭据。
